# Simple Calculator (Java)

A console calculator in Java. The user enters two numbers and an operator, and the program displays the result.

## Features
- Supports +, -, * and /
- Handles division by zero with an error message

## How to run
1. Install the Java JDK
2. Compile: `javac Calculator.java`
3. Run: `java Calculator`

## Sample output
```
Enter the first number:
3.5
Enter the operator:
*
Enter the second number:
300
Result=1050.0
```

## Concepts used
Scanner input, if-else statements, operators, data types
